TrustPort

Two composable trust-scoring services for agent-to-agent commerce. An AI agent reads the SKILL.md, queries a counterparty's reputation, and gets a payment-structure recommendation — no human help needed.

Service A — Risk Oracle

Real-time trust scoring. Query any agent ID to get their transaction history, dispute rate, and risk tier (low / medium / high). Report outcomes to keep scores accurate.

Service B — Escrow Advisor

Payment-structure recommendations. Given a counterparty and deal amount, returns whether to prepay, split-escrow, full-escrow, or decline — powered by Risk Oracle under the hood.

Composability: Escrow Advisor calls Risk Oracle as its backend. An agent only needs to call one endpoint to get a complete recommendation backed by live reputation data.
